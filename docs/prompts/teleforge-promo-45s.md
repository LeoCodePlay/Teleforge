## 一、主提示词(直接复制这一段)

请用 Remotion skill,制作一个45秒的极简风格产品宣传片,主题为:《让 AI 直接在服务器上读代码、改代码、跑命令》,风格为**极简科技编辑风(editorial minimal tech)**:浅色打底(`#F6F7F9` 背景 / `#FFFFFF` 卡片)、大量留白、瑞士网格排版、单一强调色 Teleforge 蓝 `#5B8CFF`、粗细分明的字体层级,整体干净、克制、高级,像一份排得很好的产品说明书而不是一支特效片。节奏上保持 BPM128(1 拍 = 0.46875s,全长 96 拍 = 24 小节),每2秒一个小卡点、每4秒一个大爆点,但卡点要**克制**:小卡点 = 一条细线生长 + 元素轻微上浮 4px,大爆点 = 一次整屏裁切/擦除转场 + 约 80ms 的极短白闪,靠排版的精准和留白的呼吸感制造节奏,**不要粒子爆炸、不要故障噪点、不要 RGB 分离、不要镜头抖动、不要赛博霓虹**。开头打字机:这是由 Teleforge 结合 Remotion 生成的产品片，为证明它真的能让 AI 在服务器上动手。中段围绕「SSH 常驻连接、远程↔本地双工作区、Agent 真实动手、真机浏览器扩展、AI 操控整台电脑、自动化任务、只读调研子代理、成果物交付与变更对比」展开,用真实界面卡片的 3D 悬浮、bento 网格的逐格淡入、大字数字滚动、四端并排与深浅配色对调来展示 Teleforge 的能力;结尾所有界面卡片向中心收拢成 Teleforge 标志,然后黑屏打字:让 AI 直接在服务器上写代码。

## 二、设计 Token(想要"UI 好看",就把这组值写进 `theme.ts` 别再自由发挥)

```
背景        #F6F7F9        （浅色段）
卡片        #FFFFFF
深色段背景   #0B0D10 / 卡片 #13161B
主文字      #0F1319 / 深色段文字 #E9ECF2
次文字      rgba(15,19,25,.56)
细线        rgba(15,19,25,.10)   1px,不要更粗
强调色      #5B8CFF       （只用在一条线、一个数字、一个按钮上,一屏最多一处）
强调浅底    rgba(91,140,255,.12)

圆角        卡片 20px / 小标签 999px
阴影        0 1px 2px rgba(15,19,25,.04), 0 12px 32px -12px rgba(15,19,25,.14)   ← 极轻,不要发光的黑影
间距        8 的倍数；页面左右安全边距 96px；区块之间留白 ≥ 120px

字体        标题 Inter / 思源黑体（700–800,字距 -2%）
            正文 Inter / 思源黑体（400–500）
            标签与代码 JetBrains Mono（500,全大写或小写 + letter-spacing 4%）
字号        主标题 96–128px · 段落标题 56px · 正文 28px · 标签 20px
行高        标题 1.05 · 正文 1.5

缓动        入场 cubic-bezier(.22,.61,.36,1) 320ms
            卡点弹簧 damping 200 / stiffness 100（不要弹过头）
镜头运动     只允许 translate / scale(1.0–1.04) / opacity / clip-path,禁止旋转抖动
```

三段配色备选,按调性挑一套:
1. **暖白 + 蓝**(推荐,和官网一致)——`#F6F7F9` 打底,`#5B8CFF` 点睛,最耐看。
2. **纯白 + 墨黑**——全白打底,只用黑/灰/一条蓝线,更"杂志"。
3. **浅灰 + 深色对切**——三分之二浅色 + 三分之一深色,深色留给「远程 / 终端 / 真机浏览器」段落,对比最强。

## 三、分镜卡点表(可选,贴给 Agent 让它照着走)

时间轴与 128 BPM 严格对齐:96 拍 / 24 小节 / 12 个大爆点(每 3.75s)/ 24 个小卡点(每 1.875s)。

| 0:03.75–0:09.4 | 3–5 | **主标题** | 大标题分三行逐行上浮:「让 AI 直接在服务器上 / 读代码、改代码、跑命令」;底部一条蓝色细线从左到右长满;右下角一枚极小的 logo | 每小节一次上浮(错开 80ms) |

| 0:15–0:22.5 | 9–12 | **三步流程** | 横向三段式:① 连上服务器并选工作区 ② 一句话下指令 ③ Agent 真实动手（文件面板 → 对话与工具行 → 终端输出）;每段一张真实界面卡片,以 6° 倾斜 3D 悬浮推入,标签小字从卡片边缘滑出 | 每段落位一次小卡点(线生长 200ms) |

## 四、交付与技术约束

- 输出:**1920×1080 / 30fps / 45s / MP4(H.264)**,另出一版竖屏 1080×1920 给移动端。
- 全部用代码生成:**不要外部下载素材、不要 AI 生图**,线、网格、卡片、打字机一律用 Remotion 的 `interpolate` + `spring` + CSS/SVG 自己画,保证可复现、可改参数。
- 可用依赖:`@remotion/transitions`(只用 `fade` / `slide` / `wipe` / `clockWipe` 这类克制的过渡)、`@remotion/google-fonts`(Inter + JetBrains Mono)、`@remotion/shapes`。**不要引入 `@remotion/three`、不要引入噪声包**——极简风格不需要。
- 卡点统一封装:`const beat = (f) => Math.round((f / fps) * (128 / 60))`,所有动画时长用「拍」为单位写,别写死毫秒。
- 整套视觉集中在一个 `theme.ts`(上面的 token)+ 一个 `<Grid>` 组件里,**先搭一个静态画面把排版调到满意,再开始加动画**——极简片的成败 80% 在排版。
- 真实素材直接用(本仓库现成,别再造):
  - 产品 Logo:`docs/logo/lockups/dual-arrow-t-lockup.svg`、`docs/logo/tiles/*.svg`、`website/public/teleforge-mark.svg`(纯色 `#5B8CFF`)
  - 主界面截图:`docs/images/homepage.png`
  - 实拍界面切片:`website/public/shots/` 下的 10 张——`app-overview` / `agent-chat` / `agent-tools` / `files-panel` / `editor` / `terminal` / `browser-preview` / `ssh-profiles` / `settings` / `mobile`,它们是这支片的画面主角,务必裁成统一圆角卡片再上屏。
- 音频:自己合成一条 128 BPM 的极简电子鼓点(干净 kick + hi-hat,不要失真吉他/警报音),做成独立 Composition;卡点必须真实踩在音频上。
- 交付时给出:`npx remotion studio` 能直接预览的工程 + 渲染命令。

## 五、明确不要出现的东西(防走偏)

❌ 粒子爆炸 / 星云 / 光缆隧道 ❌ 故障噪点、扫描线、RGB 分离、画面抖动
❌ 霓虹紫粉渐变、发光描边、大面积深空黑 ❌ 旋转、翻转、弹跳过头的弹簧
❌ 一屏塞三行以上的小字 ❌ 左右满铺的装饰性网格线、科技感 HUD 边框
✅ 结论:一屏只讲一件事,靠留白、对齐和一条蓝线说话。
