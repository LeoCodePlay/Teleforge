## 一、爆款标题的 8 种类型（附本项目示例）

B站信息流的判断窗口只有 **1.8–2.3 秒**，标题和封面共同决定点击率，而点击率是推荐权重的核心因子。所以标题只干一件事：**在 3 秒内给出一个「值得点」的理由**。

### 1. 悬念缺口式（信息差驱动）
**公式**：`做了一件反常的事 + 但/然后……`
- 我把 AI Agent 装进了服务器，然后它自己把代码改完了
- 给 AI 开了 SSH 权限后，我的服务器开始自己干活

> 有效原因：好奇心缺口是最稳的点击模型，适合有「演示画面」的技术视频。

### 2. 身份 + 痛点式（人群自投罗网）
**公式**：`人群词 + 高频痛点 + 解法`
- 还在 SSH 里手敲命令？后端/运维必备的 AI 助手
- 受够了 scp 来回传文件？让 AI 直接上机改代码

> 人群词（运维 / 后端 / 远程开发 / 学生党 / 独立开发者）是 B站最强的召唤咒。

### 3. 数字清单式（降低预期成本）
**公式**：`数字 + 强收益`
- 3 分钟让 AI 在你服务器上读写代码（开源）
- 5 个功能点，讲清我为什么重写了一个远程开发工具

> 数字给的是「时间成本承诺」，观众敢点。

### 4. 对比 / 颠覆式（借已有认知）
**公式**：`不用/不装 X + 我也能做到 Z`
- 不用 VSCode Remote，AI 也能在我的服务器上干活
- 把 Xshell + AI 插件删了，我换成了这一个开源工具

> 用观众已知的产品当锚点，理解成本最低。

### 5. 开源 / 白嫖式（B站强情绪词）
**公式**：`开源 / 免费 / 自部署 / 白嫖 + 项目名`
- 开源了！一个能 SSH 进服务器干活的 AI 编程工具
- 完全开源免费，自己部署，代码和密钥都不出你的机器

> 「开源」在 B站不只是许可协议，是一种情绪标签，技术区转化极高。

### 6. 自研 / 独立开发式（人味 + 背书）
**公式**：`我写了 / 我从零做了 + 东西 + 已开源`
- 我写了一个远程 AI 编程工具，现在开源给大家用
- 独立开发 4 个月，我把 AI 塞进了 SSH

> 观众愿意为「真做出来的人」停留，也更容易投币关注。

### 7. 保姆级 / 教程式（吃搜索流量）
**公式**：`保姆级 / 手把手 / 从零 + 具体任务`
- 保姆级：5 分钟把 AI 编程助手接到你的服务器上
- 手把手教你部署一个远程 AI 编程环境（开源）

> 这类标题播放不一定爆，但**长尾搜索流量最稳**，而且涨的是精准粉。

### 8. 提问 / 对号入座式（让观众自己回答）
**公式**：`疑问句 + 强相关场景`
- 远程开发到底怎么做才不折腾？我做了个工具
- AI 能在你的服务器上真实执行命令，是一种什么体验？

## 八、发布小贴士

1. **前 5 秒必须出结果画面**：AI 在服务器上改代码的实录，比任何口播都强。
2. **三段式标题**（定位词 + 核心卖点 + 行动指令）比纯标题党更适合技术区，B站的算法和观众都吃「精准」这一套。
3. **简介里的链接放前面**，别埋在长文案最后 —— 很多人只看到前两行。
4. **发布后 1 小时内回评论**：早期互动率对推荐权重影响明显。
5. **别用极限词**（最强、第一、永久免费这类容易被限流），GPL-3.0 说「开源」就够。
6. 发布前对着投稿页核对一次：标题 ≤80 字、标签 ≤10 个、简介是否被分区截断。
