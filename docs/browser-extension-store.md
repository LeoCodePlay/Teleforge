# 上架材料:Teleforge Auto(Chrome Web Store / Edge Add-ons)

扩展目前靠「开发者模式 + 加载已解压的扩展程序」分发,这是最大的转化漏斗。
本文是上架所需材料的底稿(文案、权限说明、隐私声明、审核话术、提交步骤),
实际提交需要账号与人工点击,代码侧已经准备好(1.1.0,含 `debugger` 权限的正当性说明)。

---

## 1. 商店文案

**名称**:Teleforge Auto

**简短说明(≤132 字符)**:
> 让本机 AI(Teleforge)操作你真实的 Chrome:点击、输入、批处理,复用现有登录态,默认不抢焦点。

**详细说明**:

```
Teleforge Auto 把你看得见的这个浏览器接入本机的 Teleforge AI。
AI 可以直接在带登录态的页面上开标签、点按钮、填表单、读内容,不用另开无头浏览器,也不用重新登录。

· 复用真实登录态:你已经在用的 Chrome/Edge,cookie、扩展、密码管理器全都照旧
· 批处理:一整段流程(点击→等待→输入→断言)一次跑完,而不是一步一步点
· 稳定快照:给 AI 的是结构化的页面描述,元素引用跨轮稳定,支持 Shadow DOM 与子框架
· 不打扰:AI 默认在后台标签里工作,不抢你的焦点;工具栏角标显示它正在控制几个标签
· 你可随时接管:默认只允许 AI 操作它自己开的标签;一键暂停;一键断开调试器(黄条消失)
· 数据留在本机:配对 token、操作审计都存在你自己的电脑上,不上传任何浏览内容

使用前需要在本机运行 Teleforge(桌面端或 npm run dev),配对后即可使用。
源码与说明:https://github.com/LeoCodePlay/Teleforge
```

**分类**:开发者工具 / 生产力
**语言**:简体中文(主)、English
**官网 / 支持链接**:仓库 README 与 Issues

## 2. 权限说明(审核必填)

| 权限 | 用途(给审核看) |
|---|---|
| `debugger` | 通过 Chrome DevTools Protocol 在**用户明确授权/由本扩展打开的标签**上执行点击、输入、截图、读取页面结构。输入走 `Input.dispatch*`,是可信事件;调试器按标签挂载,用户随时可在弹窗里一键断开。 |
| `tabs` | 列出标签以供用户选择「交给 AI」;打开/关闭本扩展自己创建的标签;读取标题/URL 用于会话绑定。不读取页面内容。 |
| `storage` | 在本机保存已配对的服务端地址、实例 id、暂停开关。 |
| `alarms` | service worker 保活/断线重连的兜底定时器(30s)。 |
| `scripting` | 备用:在极少数无法使用调试器的页面上做最小化读取(当前版本未启用)。 |
| `host_permissions: 127.0.0.1 / localhost` | 只与本机运行的 Teleforge 通信(HTTP 配对 + WebSocket 指令)。**不访问任何外部域名。** |

**远程代码说明(重要)**:

- 扩展不加载、不执行任何来自公网的代码;
- 页面快照脚本由**用户自己机器上的 Teleforge** 在 WebSocket 握手时下发
  (`ext_welcome.snapshotScriptSrc`),与内置预览跑同一份,目的是避免扩展与服务端两份脚本漂移;
- 该脚本只在**被授权标签的页面上下文**里执行(通过 CDP `Runtime.evaluate`),
  不进入扩展的 service worker,也不改变扩展自身逻辑;
- 如果审核认为这仍属"远程代码",替代方案已评估:把脚本打进扩展、服务端只传参数
  (代价是升级扩展才能改快照格式,且两个后端可能短暂不一致)。需要时可在 1~2 天内切换。

## 3. 隐私声明(Privacy practices)

- **是否收集用户数据**:否。
- **是否出售/转让数据**:否。
- **是否用于无关用途**:否。
- **是否用于判定信用/贷款**:否。
- 本地存储:配对 token(`data/browser-bridge.json`)、站点经验(`data/browser-learnings.json`)、
  操作审计(`data/browser-audit.log`)。全部在用户本机,不联网上传;用户可随时删除。
- 页面内容仅在本机 AI 请求时读取,并以结构化文本返回给本机 AI;扩展自身不持久化页面内容。
- 审计日志**不记录输入的具体文本**,只记录长度。

## 5. 提交步骤

**Chrome Web Store**

1. 注册开发者账号(一次性 5 美元),启用两步验证;
2. `node scripts/build-extension.mjs` 产出 `output/teleforge-auto-v1.1.0.zip`;
3. 新建条目,上传 zip,填写文案与权限说明,上传截图;
4. 隐私 → 勾选"不收集用户数据",填写单一用途说明:
   > 让用户本机的 AI 工具在用户自己的浏览器里执行网页操作。
5. 提交审核。`debugger` 权限会人工复核,预计 3~10 个工作日;被拒时附上本文第 2 节的远程代码说明。

**Edge Add-ons**

同上,无需费用;审核通常更快。注意 Edge 对 `debugger` 的说明要求同样严格。

**企业/内网分发(不等商店)**

- 注册表 `ExtensionInstallForcelist` 指向内网 CRX(需自签 + 策略);
- 或安装包内提供 `--load-extension=<dir>` 的快捷方式(仅开发/内网机器);
- 桌面端已经随安装包带一份 `extension/`,配合 popup 的「扫描全部」,内网用户不需要商店。

## 7. 已知限制(写进商店说明,减少差评)

- Chrome Web Store 政策不允许隐藏「正在调试此浏览器」黄条 —— 这是浏览器的强制行为,不是本扩展的选择;
- 被 AI 操作的标签里若打开 DevTools,调试器会被抢走(会明确报错);
- 跨进程 iframe(OOPIF)的 DOM 扩展读不到,这类页面建议用 Teleforge 的内置预览;
- 需要本机运行 Teleforge,单独安装扩展不提供任何功能(可在商店说明里显著提示)。
