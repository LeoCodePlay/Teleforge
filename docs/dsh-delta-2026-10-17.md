## 3. 评估后**未搬**(附理由)

| 项 | 理由 |
|---|---|
| DeepSeek Search / Fetch 直连 API(`fda98dadd2`) | 绑定 DeepSeek 账号与 `https://api.deepseek.com/v1/tools`;本项目 provider 由用户自配(23 家 + 自定义),没有可复用的鉴权与端点前提。若将来接 DeepSeek 官方搜索,这条是现成规格。 |
| 账号通知层叠 / 凭据检测状态(`2dcd031a8e`、`7110b615eb`) | 上游实体是「DeepSeek 账号 + 计费通知 + 账号路由模型目录」,本项目无账号体系。 |
| pi-ai 提供方目录、Azure 路由改名 | 本项目不走 pi-ai。 |
| Remote access RBAC / operator 隔离 | 单用户本地服务(默认只听 127.0.0.1),没有多主体。 |
| 插件市场、内置功能预览图、host release 刷新提示、webworker 预览 | 没有 Cordis 插件体系与多 release 热替换。 |
| CUA 的 AX 后台悬停 / 千分比相对坐标 | 实现形态不同:本项目是常驻 PowerShell worker + UIA + OCR(`server/core/computer-use/`),已具备「元素 → 屏幕物理坐标 → 截图坐标」三级定位与 `rx/ry` 相对坐标;AX 悬停在 Windows 上没有对应 API。 |
| 会话折叠动画矩阵 / 通知唤醒 Turn 分组 | 本项目过程折叠是单层 `ProcessFold`(正文不参与折叠),不存在「收起后整屏空白 + ~6000px 补白」的成因。 |
| office 渲染工具、Ralph/Workflow/Team | 与 SSH 远程编码的能力面无交集。 |
| DeepSeek Flash `1017` 角标 | 纯临时展示名,模型名由用户/提供商决定。 |

## 4. 已核对「本地本来就有」的功能(避免重复搬)

- **CUA 坐标体系**:`server/core/computer-use/index.ts:412-445` 的三级解点(`rx/ry` + 窗口 > `sx/sy` 屏幕物理 > `x/y` 截图像素)、缺失参数的逐工具中文提示、OCR 模糊匹配(`textSimilarity`)。

- **缺失退出码语义**:见上表 ⑥ 的核对结论。
- **模型菜单按提供商分组**:`ModelMenu.tsx`(提供商名为分组标题、不可选)。
- **推理等级 6 档 + 会话持久化**:`ModelMenu.tsx` 的 `REASONING_LEVELS`、`ChatPanel` 的 `sshai.reasoning`。
- **三协议方言**:`server/agent/llm.ts` 的 `buildOpenAiBody` / `buildAnthropicBody` / `buildGeminiBody`。
