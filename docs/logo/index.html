Teleforge LOGO 方案

6 个版本 · 同一套几何规则(64 网格 / 光学方框 46 / 描边 5–6 / 全圆角端点)· 深底与浅底成对给出

产品是「SSH 远程 ↔ 本地互通的 AI 编程工具」,所以每个方案都在讲同一件事:两端之间有一条保持住的连接, 并且 AI 在那头真实干活。选型只看两点——16px 还认不认得出,以及和实色界面放一起像不像一家人。 六个方案(连描边算)都收敛在 64 网格里同一个 46×46 光学方框、居中于 (32,32),并排与缩小时视觉重量一致。

双向 TDual-Arrow T

推荐主案 · 主要用途:桌面端图标 / 网页 favicon / 主视觉

深色底
浅色底

首字母 T 的骨架:顶部一条双向箭头 = 远程 ↔ 本地 双向同步;竖杆是 SSH 隧道;下端一颗绿点 = 连接保持的活口。

  • 唯一的字母骨架,缩到 16px 仍是清晰的字母形
  • 命中产品核心:远程与本地一套工具
  • 单色场景只换两色即可用
  • 元素稍多,极小尺寸(16px)下箭头会糊成短线

一对括号 = 本地与远程两台机器;门内一个 >_ 提示符 = AI 在门那侧真实执行命令。

钥匙 = SSH 私钥认证;钥匙柄是一簇熔炉火 = Forge(锻造)。合起来是「用密钥点着火」。

  • 把「安全接入 + 锻造」两层意思都装进一个形状

  • 火苗+齿纹细节多,24px 以下齿纹会基本消失

远程节点Node Orbit

最抽象 · 主要用途:图标系统 / 状态指示 / 动效场景(轨道可转)

实心圆 = 你面前的本地;环绕的弧 = 网络路径;弧上留出的缺口里坐着绿点 = 已经连上的远程服务器(连接保持)。

  • 偏抽象,单看不像编程工具,需要配字标

产物清单(全部由 build-logos.mjs 生成,改几何只需改这一处):

docs/logo/
├─ index.html                ← 本预览看板(离线可开)
├─ build-logos.mjs           ← 几何与调色板的单一事实源
├─ icon.sprite.svg           ← 6 个 symbol,页面里 <use> 复用
├─ icon.manifest.json        ← 方案清单 / 技术建议
├─ icon.spec.md              ← 图标系统规范(尺寸、描边、命名、用法)
├─ canvas.icon.demo.js       ← Canvas 绘制 + 动效起步模板
├─ concepts/                 ← 裸标(透明底,含 -light 浅底版)
├─ tiles/                    ← 圆角方形应用图标
└─ lockups/                  ← 横版标 + 字标组合

导出 PNG(桌面端图标走 Tauri 自己的流程):
npx sharp-cli -i docs/logo/tiles/dual-arrow-t-tile.svg -o /tmp/tile-1024.png resize 1024 1024
或直接 npm run desktop:icon(会读 web/public/logo.png)—— 选定方案后我再把成品同步到 web/public/ 与 src-tauri/icons/。
