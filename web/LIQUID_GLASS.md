# 液态玻璃（Liquid Glass）设计规范与风格提示词模板

> 本文档是本项目 UI 的**唯一视觉事实来源**（Single Source of Truth）。
> 任何新增页面、组件、弹窗必须遵循本文规范。文末附可直接投喂给 AI 的风格提示词模板。

---

## 一、设计理念

**Liquid Glass** = 通透的玻璃材质 + 流动的光线 + 柔软的形体。

- **材质**：界面元素像一块块悬浮的磨砂玻璃，背景的彩色光晕透过玻璃折射、晕染，形成通透的层次感。
- **光线**：每个玻璃表面都有"上亮下暗"的边缘高光（模拟环境光从上方照射），并带有一道随视角游走的镜面反光。
- **形体**：大圆角（胶囊/超椭圆），边界柔软，没有锐利的直角。
- **层次**：背景 → 光斑层 → 玻璃面板 → 玻璃控件，四层纵深，靠"模糊度 + 亮度 + 阴影"区分前后。

**禁止**：纯色扁平块、1px 硬边框无高光、大面积不透明面板、纯白/纯黑背景。

---

## 二、设计 Tokens（CSS 变量约定）

所有液态玻璃变量以 `--glass-*` 前缀声明在 `:root`，新增组件**必须复用**这些变量。

### 2.1 色彩

| Token | 值 | 用途 |
|---|---|---|
| `--bg-deep` | `#05070f` | 最底层深空底色 |
| `--glass-bg` | `rgba(255,255,255,.055)` | 普通玻璃面板底色 |
| `--glass-bg-strong` | `rgba(255,255,255,.09)` | 弹窗/悬浮层玻璃底色 |
| `--glass-bg-hover` | `rgba(255,255,255,.12)` | hover 时的玻璃底色 |
| `--glass-border` | `rgba(255,255,255,.14)` | 玻璃边框 |
| `--glass-border-hover` | `rgba(255,255,255,.28)` | hover 边框 |
| `--glass-hi` | `rgba(255,255,255,.30)` | 玻璃顶部内高光 |
| `--glass-lo` | `rgba(255,255,255,.04)` | 玻璃底部内光 |
| `--accent` | `#6aa8ff` | 主强调色（冰蓝） |
| `--accent-glow` | `rgba(106,168,255,.45)` | 强调色光晕 |
| `--green / --red / --amber` | `#4ade80 / #fb7185 / #fbbf24` | 状态色（自带发光） |

### 2.2 材质

| Token | 值 | 用途 |
|---|---|---|
| `--blur-sm` | `blur(10px) saturate(150%)` | 列表行、小控件 |
| `--blur-md` | `blur(20px) saturate(170%)` | 面板、侧栏、工具栏 |
| `--blur-lg` | `blur(32px) saturate(180%)` | 弹窗、菜单、输入卡 |
| `--r-sm / --r-md / --r-lg / --r-pill` | `10px / 14px / 20px / 999px` | 圆角梯度 |

### 2.3 玻璃阴影（三段式，缺一不可）

```css
box-shadow:
  inset 0 1px 0 var(--glass-hi),        /* ① 顶部边缘高光 */
  inset 0 -1px 0 var(--glass-lo),       /* ② 底部边缘微光 */
  0 8px 32px rgba(0,0,0,.35);           /* ③ 悬浮外投影 */
```

## 三、背景规范（玻璃的生命线）

玻璃必须有东西可"透"。背景分三层，**禁止**把 app 背景写成纯色：

1. **深空基底**：`#05070f` 的深蓝黑。
2. **极光光斑层**：`body` 上叠 3~4 个大型 `radial-gradient` 光斑（冰蓝/青/紫罗兰），用 `@keyframes` 让它们缓慢漂移（30s+ 周期，只动 `transform`）。
3. **噪点层**（可选）：极低透明度的 SVG 噪点，消除渐变色带。

---

## 四、组件级应用规则

| 组件类型 | 材质要求 |
|---|---|
| 顶栏 topbar | `--blur-md`，底部渐隐分隔线而非实线 |
| 侧边栏 sidebar | `--blur-md`，右侧边缘 1px 渐变高光 |
| 主按钮 primary | 冰蓝实色 + 顶部光泽 `inset 0 1px 0 rgba(255,255,255,.4)` + 悬浮光晕 |
| 普通按钮 | 玻璃胶囊，hover 提亮并上浮 1px |
| 输入框 | 玻璃内嵌（比面板更暗一档），聚焦时边框发 `--accent-glow` |
| 聊天输入卡 composer | `--blur-lg` 厚玻璃 + 大圆角，聚焦时整体发光 |
| AI 气泡 | 玻璃材质；用户气泡用 accent 渐变实色 |
| 弹窗 modal | `--blur-lg` + `--glass-bg-strong` + 大阴影 + 淡入缩放动画 |
| 右键菜单/下拉 | 同弹窗，但更小圆角 |
| Tab 标签 | 选中项为发光玻璃胶囊（iOS 分段控件风格） |
| 终端 xterm | **例外**：保持近黑不透明底（#0a0d14），保证终端对比度 |
| 列表行 | 不用 backdrop-filter（性能），用半透明白底 hover |

## 五、交互与动效规范

- **hover**：背景提亮 `.12`、边框 `.28`、`translateY(-1px)`，时长 `.18s`。
- **active**：`scale(.97)` 回弹。
- **弹窗进入**：`opacity 0→1` + `scale .96→1`，180ms ease-out。
- **光泽流动**：主按钮/品牌区可加 135° 移动的镜面高光（`background-position` 动画，6s 循环）。
- **焦点环**：`box-shadow: 0 0 0 3px var(--accent-glow)` 取代默认 outline。

---

## 六、性能红线

1. `backdrop-filter` 只用于**容器级**元素（顶栏/侧栏/弹窗/输入卡/菜单），**列表行、消息气泡内层禁止使用**。
2. 背景光斑动画只用 `transform`，禁止 animate `background`。
3. 单屏 `backdrop-filter` 元素 ≤ 15 个。
4. 所有动画时长 ≤ 30s（背景漂移除外），避免持续重绘。

## 七、可复用的 AI 风格提示词模板

> 复制以下模板，替换 `{{...}}` 占位符，即可让任何 AI 生成符合本规范的界面/组件。

```text
你是资深 UI 设计工程师。请为「{{项目名：远程 SSH AI 编程工具}}」实现/新增
「{{组件名，如：设置弹窗 / 文件管理器}}」，必须严格遵循以下【液态玻璃 Liquid Glass】风格规范：

【材质核心】
1. 玻璃底色：linear-gradient(135deg, rgba(255,255,255,.08), rgba(255,255,255,.03))；
   悬浮层用 rgba(255,255,255,.09)+。
2. 模糊：容器用 backdrop-filter: blur(20px) saturate(170%)（弹窗 32px）；
   列表行/小控件禁止 backdrop-filter，只用半透明白底。
3. 三段式阴影（必须同时存在）：
   inset 0 1px 0 rgba(255,255,255,.30) /* 顶部高光 */,
   inset 0 -1px 0 rgba(255,255,255,.04) /* 底部微光 */,
   0 8px 32px rgba(0,0,0,.35)          /* 悬浮投影 */。
4. 边框 1px rgba(255,255,255,.14)，hover 提亮到 .28。
5. 圆角：小控件 10px、面板 14px、弹窗 20px、胶囊按钮 999px。

【色彩】
- 深空底 #05070f；主强调 冰蓝 #6aa8ff（发光 rgba(106,168,255,.45)）；
- 状态色：成功 #4ade80 / 危险 #fb7185 / 警告 #fbbf24，均带同色系 40% 透明边框。
- 文字：主 #e2e8f0 / 次 #8a93a6。

【背景（必须有，玻璃靠它成活）】
底层 #05070f 上叠 3-4 个大 radial-gradient 彩色光斑（冰蓝/青/紫罗兰，透明度 ≤ .18），
用 30s+ 的 transform 缓慢漂移；禁止纯色背景。

【交互】
- hover：提亮 + translateY(-1px)，.18s；
- active：scale(.97)；
- 弹窗进入：淡入 + scale .96→1，180ms；
- 焦点：0 0 0 3px rgba(106,168,255,.45)，禁用默认 outline。
- 主按钮：冰蓝实色 + 顶部光泽 + 悬浮光晕。

【例外】
终端/代码区保持近黑不透明底（#0a0d14）保证可读性。

【交付要求】
- 只输出 CSS/JSX，复用既有 CSS 变量（--glass-*、--accent、--blur-*）；
- 不引入新依赖；动画只用 transform/opacity；
- 中文界面文案；等宽字体 JetBrains Mono 用于路径/命令/代码。
```

## 八、验收清单（新组件合并前自查）

- [ ] 玻璃元素同时具备：渐变底色 + backdrop-filter + 三段式阴影 + 半透明边框
- [ ] 列表行未使用 backdrop-filter
- [ ] 圆角符合 token 梯度，无直角
- [ ] hover/active/focus 三态齐全
- [ ] 深底上文字对比度 ≥ 4.5:1（终端区除外）
- [ ] 弹窗有入场动画，背景光斑可见
- [ ] 复用了 `:root` 中的设计变量，无硬编码色值（状态色边框除外）
